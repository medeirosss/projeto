Compliance de Ativos

Defina até três padrões independentes de nomenclatura: Servidores, Desktops e Nós de rede.

Como funciona

Cada regra é avaliada separadamente. Os campos preenchidos são cumulativos: se Início e Final forem definidos, ambos precisam casar. O Magi usa essa conformidade como uma evidência de confiança; o técnico não altera os pesos.

Pontuação

Modelo transparente usado pelo Confidence Engine.

Faixas de confiança
Princípio

O técnico define o que é compatível com o ambiente por meio do Compliance. O Magi mantém pesos fixos para que 80% tenha o mesmo significado em qualquer instalação. A pontuação é limitada entre 0 e 100.
