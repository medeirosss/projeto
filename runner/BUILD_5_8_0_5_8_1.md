# MAGI 5.8.0 + 5.8.1 — Security Baseline / Change Detection

- Snapshot imutável por execução, com `schema_version=1`.
- Comparação conservadora com baseline anterior da mesma Campaign.
- Endpoint `GET /api/attack-simulator/campaigns/{uuid}/baselines`.
- Botão **Encerrar Campaign** usa finalização normal, com motivo `manual_completed`.
- Jobs pendentes/running de paths da execução são marcados cancelados; um job já em execução no Windows pode ainda completar fisicamente, e o Runner deve respeitar cancelamento.
- IP não observado ou não avaliado é `INCONCLUSIVE`, nunca `REMOVED`.
- O pipeline e a política 10/5/3/0 foram preservados.

## Homologação
1. Migrar banco e iniciar serviços.
2. Criar Campaign e encerrar manualmente; conferir `stop_reason=manual_completed` e snapshot.
3. Executar segunda Campaign com mesmo UUID e comparar via endpoint baselines.
4. Verificar não regressão de DHCP, Runner e Attack Path.

**Limitação:** testes integrados com PostgreSQL e Runner Windows precisam ser executados no ambiente do cliente.
